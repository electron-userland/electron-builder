feat(updater)!: a missing NSIS update installer (`ENOENT`) fails the install with `ERR_UPDATER_INSTALLER_START_FAILED`; electron-updater neither starts it elevated nor opens it with the shell. `quitAndInstall()` and the install on launch wait for the installer to start and keep the app running when the start is refused or fails. `elevate.exe` (for `isAdminRightsRequired` and the retry after `EACCES` or `UNKNOWN`, e.g. AppLocker or WDAC rules that let only administrators run the installer) runs only when the current user cannot modify it, its folder or the install folder of the app; elsewhere the installer is started directly, which installs in an app that runs with administrator rights and fails with `ERR_UPDATER_INSTALLER_ELEVATION_REFUSED` in any other, so an update cannot switch an app installed per user to a per-machine build unless the app runs with administrator rights: install per-machine apps into a folder only administrators can write, e.g. with `nsis.perMachine: true`
